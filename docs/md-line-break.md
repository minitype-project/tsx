# Markdown における改行

1. 和文 + 和文 の改行，和文 + 欧文の改行，欧文 + 和文の改行では，改行もスペースも入れない．

文字のカテゴリは以下のように判定する．
- 和文：CJK 統合漢字，ひらがな，カタカナ，全角文字（`。`，`、`，`「」` 等）
- 欧文：その他．

改行の前後にインライン要素がある場合，その内側の先頭または末尾の文字を用いて判定する．
先頭または末尾に不可視コンポーネント（`<Ref/>`，`<Fn/>` 等）が現れる場合，それを飛ばして前後の文字で判定する．
文字が見当たらない場合は和文として扱う．

```
和文．
和文．
```

```
和文．
This is a sentence.
```

```
This is a sentence.
和文．
```

2. 欧文 + 欧文 の場合，改行をスペースに変換する．

```
//  This is a sentence. This is a sentence.
This is a sentence.
This is a sentence.
```

3. 和文，欧文に関わらず，空行を入れた場合には改段落として扱う．

```
和文．

和文．
```

```
This is a sentence.

This is a sentence.
```

4. 行末にスペース 2 つ，または <Br /> を挿入した場合，改行される．

```
和文．  
和文
```

```
和文<Br />
和文
```
